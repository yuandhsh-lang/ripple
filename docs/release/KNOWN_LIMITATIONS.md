# 已知限制与真实验收边界

- 仅 Windows 官方 RC6；未在第二台设备、macOS、Linux 或移动端实测。没有普通无经验用户测试。
- 一个主活动和最多四项关联事实，同城同日 Asia/Shanghai，15–240 分钟。搜索粒度和最多两项移动限制意味着不保证找到所有数学上可能的解。
- 天气以 Open-Meteo 降雨量、概率、天气代码及完整覆盖为依据；未新增未经依据验证的风温阈值。缺失、过期不是安全。
- 没有外部日历写入、ICS 同步或后台常驻监控；Glance 是宿主原生提醒，不声称已经验证 Windows 通知中心。
- 暖启动点击风险卡片可打开 Ripple，但可能需点击“查看系统提醒状态”消费 route；v0.6.4 录像曾观察到 Toast；v0.6.5 本日实测有面板卡片、route 消费及撤回证据，但瞬时 Toast 未稳定捕获，不保证所有 Windows 通知配置均可用。
- 历史 SDK 的 64 ms 间歇脚本墙钟超限未完全归因。当前完整严格测试成功只能证明该次运行，不能覆盖历史失败或证明永不超时。宿主和 SDK 未修改，预算和断言未放宽。
- 真模型曾完成工具、无解协商及数值说明的一次定向纠正。非法候选的一次纠正已有受控 SDK 测试；真模型负例未必触发，不声称所有纠错路径真实 Provider 通过。
- 顺序写入不是原子事务，也无跨进程 CAS。出现部分/未知结果停止并只读核对；不自动重放或回滚。仅在单宿主运行本应用的支持范围内验收。
- v0.6.4 的 GitHub Release、来源证明、下载包安装及实机视频已完成；App Hub 审核不是 Release 工作流的结果。新的产品演示只更新媒体，不改变认证包。赛事历史冻结版本与赛后产品演示分别保留。

- v0.6.5 以 GO_WITH_KNOWN_RISKS 推进发布：当前严格测试及本机 RC6 核心任务通过，无观察到的新增 P0；不是历史初始化超时已经修复。ICS 只读快照限制与最多 32 条历史摘要见 [版本说明](V0.6.5.md)。
