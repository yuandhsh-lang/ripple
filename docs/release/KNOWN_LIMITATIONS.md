- 仅 Windows 官方 RC6；未在第二台设备、macOS、Linux 或移动端实测。没有普通无经验用户测试。
- 一个主活动和最多四项关联事实，同城同日 Asia/Shanghai，15–240 分钟。搜索粒度和最多两项移动限制意味着不保证找到所有数学上可能的解。
