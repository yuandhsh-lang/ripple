# Ripple 0.6.5

导入已有会议，让 AI 安排活动时避开外部占用；在软件里查看最近的审批和执行记录。

- **ICS 导入**：使用宿主文件选择器读取日历文件，先完整校验再替换快照。UTC / Asia/Shanghai、普通同日事件和单日全天事件；最多 32 项、32 KiB。复杂重复规则与不支持的时区明确拒绝。外部事件只读，工具只得到必要时间占用，不发送原文件。
- **执行历史**：按需查看最近 32 条摘要，分别显示批准、拒绝、执行与独立核验。重启仍可查看；它不是完整或不可篡改台账，异常时以实际收据和持久化读回为准。
- 原有自然语言草稿、Open-Meteo、Agent 工具、约束协商、整组审批、唯一执行与独立读回保持不变。新导入影响规划时，旧建议和批准失效。

## 验证

相同业务源码在官方 Windows RC6 隔离环境完成文件选择器导入、真实 DeepSeek 两个工具、LIVE 天气、避开外部会议的两项改期、独立审批与读回、历史查看和重启一致。未在第二台设备验证。
