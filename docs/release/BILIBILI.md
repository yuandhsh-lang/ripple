这段视频记录 Ripple 在官方 OctoSense 中的一次任务：自然语言整理计划，查看天气与风险提醒，AI 调用工具发现原窗口无解，与用户协商新条件，再由用户单独批准两项改期。应用实际保存后，重新读取持久化结果，显示逐项核验。

应用：Ripple 0.6.4，固定 Tag v0.6.4。开源地址：https://github.com/yuandhsh-lang/ripple
下载与复现：https://github.com/yuandhsh-lang/ripple/releases/tag/v0.6.4

真实性说明：画面为官方原版 RC6 中的软件操作录屏，不是生成式视频或前端原型。DeepSeek、工具调用、Glance、审批与保存均为实际运行；先访问 LIVE 天气，再以画面标明的 FIXTURE 快照验证降雨变化。只剪去等待和导航时间，最后展示同一任务重启后数据保留。中文解说使用本机 TTS。

当前只管理 Ripple 内部计划，不同步外部日历，不提供全天后台监控。支持中国同城同日、北京时间、15–240 分钟活动；Glance 暖态可能需要额外点击。详细限制见仓库。
