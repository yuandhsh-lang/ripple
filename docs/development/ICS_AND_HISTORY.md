# ICS 与执行历史（0.6.5 本地候选）

正式 v0.6.4 不变。此分支是未发布候选，不能用旧版实机记录代替新功能验收。

## 使用

在 Ripple 下方点击“导入已有日历（ICS）”，在宿主文件选择器选择文件。导入会替换本应用上一次导入快照，不影响自有计划，不写回源文件。读取和校验全部成功才采用；相同 UID 内容重复导入为无操作。来源、数量、范围和导入结果在本页显示，展开可看每个只读事件。

支持 UTF-8、CRLF/LF、折叠行、文本转义、UID/SUMMARY/LOCATION、DTSTART/DTEND、SEQUENCE/DTSTAMP。只接受 UTC 或 Asia/Shanghai 同日日期时间及单日全天事件。全天结束日期按排他边界处理。拒绝浮动时间、未知时区、跨日、RRULE/RDATE/EXDATE/EXRULE/RECURRENCE-ID、复杂组件、DURATION、取消消息、透明事件及互相冲突的同 UID 版本；不会悄悄丢弃。上限为 32 KiB、512 物理行、单个展开字段 2048 字节、32 个事件。

占用以 external-calendar.json 保存在应用沙箱；schema 3 日程不变。规划上下文仅传递目标日期占用时间，不发送外部标题、地点、UID 或完整原文。旧批准绑定导入快照版本，执行前另读快照原始字节；发生变化即阻断。

“执行历史”按需读取最多 32 条摘要，每页 8 条。它来自操作状态及独立读回收据，不是不可篡改台账，不补造旧历史。授权与执行成功分开显示。损坏/写失败提示不完整，实际执行结果以“核对最近执行收据”为准。新摘要异步保存，突发关闭可能缺少尚未写出的摘要；执行收据原有恢复规则仍有效。

## 验证

使用 phase1/business-harness 的现有命令运行严格 SDK 测试；ics_tests.rs 通过实际 Splash VM、真实文件系统和工具 ABI 检查解析、污染输入、上限、占用搜索、旧批准、历史拒绝/取消/损坏。stage3_tests.rs 额外检查真实执行器产生的两项核验历史和部分失败历史。测试天气与模型选择为受控夹具，不等同真实 RC6 / DeepSeek 验收。

原生文件选择器、Provider 授权和正式 RC6 安装结果必须以本轮外部审计的 RC6_REAL_TEST.md 为准。没有修改宿主、SDK 预算、工具写权限或核心执行成功判定。
